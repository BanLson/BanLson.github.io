# 大模型应用开发（Agent）七步学习路线

> 内容整理自抖音视频，按画面文案与口播（ASR）逐帧校对后还原。
> 视频时长 65.7 秒，共 7 个步骤（画面标注 STEP 01/07 — STEP 07/07）。

## 一、整体逻辑

七步不是并列的知识点，而是一条有先后依赖的路径：

1. **地基**：Python 基础（第 1 步）
2. **通链路**：真正调通一次大模型 API（第 2 步）
3. **懂原理**：核心概念 + 手搓 ReAct 循环（第 3 步）
4. **成体系**：跟一套系统教程（第 4 步）
5. **看顶级实现**：精读优秀开源项目源码（第 5 步）
6. **补关键能力**：RAG 知识库问答（第 6 步）
7. **做工程化**：主流框架（第 7 步）

一句话版本：**先能跑，再懂原理，再看高手怎么写，最后才上框架。**

---

## 二、七步详解

### 第 1 步｜先打好 Python 基础语法

**要做什么**
这是所有后面的地基。推荐去哔哩哔哩看黑马程序员的课程，跟着敲一遍，能写变量、函数、文件读写和简单脚本就够用了。

**关键词**：Python 基础 / 函数与文件 / 黑马程序员

**阶段提醒**
这一阶段**别追求全学完**。目标是能看懂 Agent 示例代码，并能自己改几行。

---

### 第 2 步｜发一个请求，调通大模型

**要做什么**
学会用 Python 发送一个网络请求，同时去申请一个大模型 API Key，亲手完成一次对模型服务的调用。

**关键词**：HTTP 请求 / API Key / 模型调用 / JSON

**交付物**
一段能跑通的脚本：输入一句话，终端里拿到模型返回结果。

---

### 第 3 步｜搞懂核心概念，手搓 ReAct 循环

**要做什么**
搞懂 Skills、MCP、Prompt、Function Call。理解之后，试着自己动手搭一个最简单的 ReAct 循环，也就是让模型「思考再行动」。

**关键词**：Skills / MCP / Prompt / Function Call / ReAct

**学习方式**
这一步**不用找教程**。可以直接问 AI，让它边解释概念、边把循环代码写出来。

---

### 第 4 步｜系统学习 Hello-Agents

**要做什么**
去学习 Hello-Agents 这个网站，它会带你对 Agent 开发建立更系统、更深入的理解。

**配套资源**
- 在线阅读：<https://hello-agents.datawhale.cc/>
- 开源仓库：<https://github.com/datawhalechina/hello-agents>
- 说明：Datawhale 社区的系统性智能体学习教程，从零开始、理论与实战并重。

---

### 第 5 步｜精读一个优秀开源项目

**要做什么**
去 GitHub 上找一个优秀的 Agent 项目，精读它的源码。强推 **how-claude-code-works**，带你逐行精读 Claude Code 源码，真正看懂顶级 Agent 的架构设计。

**配套资源**
- 仓库：<https://github.com/Windy3f3f3f3f/how-claude-code-works>
- 在线阅读：<https://windy3f3f3f3f.github.io/how-claude-code-works/#/>

**阅读方法**
**别只看 README。** 重点看四块：入口、工具调用、上下文管理和错误处理。

---

### 第 6 步｜学习 RAG 基本原理

**要做什么**
也就是**检索增强生成**。推荐 B 站的这个视频，能带你从零到一把 RAG 彻底搞懂。

**画面中的推荐视频**
《【大模型RAG】2026年B站最全最细的（RAG知识库搭建）系统教程，手把手教你搭建私有知识库，从入门到实战全流程教学》——在哔哩哔哩搜索该标题即可。

**为什么重要**
这一块是 Agent 做知识库问答的关键。先理解**切分、向量化、召回、重排**，再去写代码会顺很多。

**关键词**：检索增强生成 / 知识库 / 向量检索

---

### 第 7 步｜上手主流框架

**要做什么**
学习 LangChain、LangGraph 这些主流框架。可以自学，多问 AI，也可以直接在哔哩哔哩上搜相关视频跟着做。

**关键词**：LangChain / LangGraph / Agent 编排 / 工程落地

**顺序提醒**
**框架放在最后学。** 先有底层心智，再学框架，才不会被 API 带着跑。

---

## 三、验收清单

按视频给出的阶段目标，可以用这几条自检是否该进入下一步：

- [ ] 第 1 步：能看懂 Agent 示例代码，并能自己改几行
- [ ] 第 2 步：有一份能跑通的脚本，输入一句话能拿到模型返回
- [ ] 第 3 步：能讲清 Skills / MCP / Prompt / Function Call，并手写过一个最小 ReAct 循环
- [ ] 第 4 步：过完 Hello-Agents，对 Agent 开发有系统认知
- [ ] 第 5 步：读完一个 Agent 项目的入口、工具调用、上下文管理和错误处理
- [ ] 第 6 步：能讲清 RAG 的切分、向量化、召回、重排
- [ ] 第 7 步：能用 LangChain / LangGraph 把前面学过的东西串成一个可运行的项目

---

## 四、视频里最值得记住的 5 句话

1. Python 是「所有后面的地基」，但这一阶段别追求全学完。
2. 学大模型的第一步不是看论文，是**自己调通一次 API**。
3. 概念不用等教程，**直接问 AI**，让它边讲边写代码。
4. 看开源项目**别只看 README**，看入口、工具调用、上下文管理和错误处理。
5. **框架放在最后学**，否则容易被 API 带着跑。

# 学习笔记

记录学习过程中的概念理解、方法总结与复盘。目标不是堆砌摘抄，而是让未来的自己能够快速回忆起「为什么学、学到什么、怎么用」。

### [示例：用四步法整理主题笔记](./example-study-note)

用「问题—概念—例子—行动」四个部分，把一次主题学习整理成结构清晰、可以回看的笔记。

## 这个分类适合放什么

- 某个主题的系统学习记录
- 对关键概念的解释与类比
- 学习后的复盘、疑问和下一步计划
- 课程、书籍或文档的阅读笔记

## 写作建议

1. 先写清楚这篇笔记要解决什么问题。
2. 用自己的话解释概念，并保留来源链接。
3. 至少给出一个可验证的例子。
4. 在结尾写下下一步行动，而不是只做摘抄。

## 关于本站

这是一个使用 [VitePress](https://vitepress.dev/) 构建的个人知识库，内容以 Markdown 编写，支持本地全文搜索、深浅色模式和手机浏览。

- **内容组织**：顶部导航按分类进入，左侧查看分类目录，中间阅读正文，右侧跳转本页小节。
- **示例说明**：当前三个分类各有一篇示例文章，均在正文开头明确标注，用于展示写作与排版方式，不代表个人经历。
- **持续维护**：新增文章和发布流程见[站点维护说明](/guide/maintenance)。

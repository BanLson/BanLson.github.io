# 实践案例

用完整案例记录一件事从需求到收尾的过程。案例不必宏大，但要能说明背景、选择、步骤、结果和可复用的经验。

## 这个分类适合放什么

- 一个完整项目的实施过程
- 一次自动化或流程优化
- 一个问题从排查到解决的全过程
- 可复用的方案对比与决策记录

## 写作建议

1. 先交代背景、目标和约束条件。
2. 记录做过的选择，以及为什么这样选。
3. 保留关键步骤、配置和验证方式。
4. 结尾总结结果、不足和下次可以改进的地方。
